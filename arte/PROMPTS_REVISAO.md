# Gods Kodex — Prompts de arte para revisão

Estilo aprovado: pixel art (pixelPerfect_v20), 768×1024 (3:4 em pé). Só a ilustração, sem moldura nem texto.

O script adiciona a todos os prompts:

- **Prefixo:** `pixel art, masterpiece, best quality, detailed pixel art, 16-bit, limited palette, vertical composition, dark background,`
- **Negativo:** `lowres, blurry, text, watermark, signature, jpeg artifacts, worst quality, bad anatomy, smooth shading, 3d render, frame, border, card, letters, multiple views`

Nada foi gerado ainda (exceto as 4 cartas do Abismo, geradas no teste do pipeline). Para mudar um prompt, edite o bloco `## Prompt de arte` no arquivo da carta.
